This is the Self-Correcting RAG Agent project.

IMPORTANT:
I already have a KNOWN-WORKING RAG baseline code (inside Rag folder). DO NOT destroy, unnecessarily rewrite, or replace its existing functionality.

The current backend can successfully:

- Load a PDF using PyPDFLoader
- Split the PDF using RecursiveCharacterTextSplitter
- Generate embeddings using local HuggingFace embeddings
- Store embeddings/documents in Chroma
- Retrieve relevant chunks using similarity search
- Send retrieved context to Gemini
- Answer questions based on the PDF
- Preserve multi-turn conversation using Gemini chat
- Return page/source information where available

The baseline code is the reference implementation.

First understand how the existing implementation works. Preserve its behavior and improve it incrementally.

VERY IMPORTANT:
DO NOT USE ANY OPENAI MODEL OR OPENAI API.
No GPT models.
No OpenAI embeddings.
No OpenAI rerankers.
No OpenAI evaluation models.

Use Gemini models where an LLM is required (uptodate model), and prefer local/open-source models for embeddings and reranking whenever practical.

============================================================
PHASE 11 — ANTI-HALLUCINATION
============================================================

The main purpose of this project is:

AVOID CONFIDENT WRONG ANSWERS.

Implement strict behavior:

If retrieved context is insufficient:

1. Do not immediately generate an answer.
2. Grade the context.
3. Rewrite the query if appropriate.
4. Retrieve again.
5. Rerank again.
6. If evidence is still insufficient, explicitly tell the user that the answer could not be found in the document.

The model must not invent information.

Every answer should preferably have source/page citations.
